# tt-065: Fragmented Turn Holding

Discuss whether trips should be carefully planned or spontaneous. Each speaker should explain their view and respond to the other person's reasons.

## Target Behavior

The manipulated speaker should defend their view using repeated fragmented pauses while continuing to hold the floor. The partner should respond naturally but may find it hard to know when to enter.
