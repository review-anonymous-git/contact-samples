# tt-031: Premature Entry

Some people think trips should be carefully planned in advance, while others think trips are better when they are spontaneous. Discuss which style you prefer and why. Try to compare concrete examples such as transportation, budget, activities, and stress.

## Target Behavior

The manipulated speaker should begin responding slightly before the partner has fully completed a point. Aim for early entry roughly once every 1-2 turns when it feels natural; do not make it so frequent that it sounds scripted or aggressive.
